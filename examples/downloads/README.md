# XML descargables

Estas dos facturas de prueba se derivaron de los XML aportados por el usuario.
Se conservaron las descripciones, cantidades, subtotales, impuestos, moneda y totales para probar la extracción y clasificación.

Se sustituyeron las claves, consecutivos, fechas y nombres de proveedor por valores de ejemplo. Se omitieron identificaciones, receptores, direcciones, teléfonos, correos, firmas, certificados y otros campos ajenos a la extracción. No tienen firma ni validez tributaria y no pretenden cumplir el XSD completo.

- `factura_ejemplo_01.xml`: siete líneas.
- `factura_ejemplo_02.xml`: tres líneas.

Se ofrecen desde la barra lateral. Los tres XML de la carpeta superior siguen siendo el lote del botón «Probar con tres facturas de ejemplo».
